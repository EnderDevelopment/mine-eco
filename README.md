# MineEco: Economy and Mining Plugin for Minecraft 1.8.8

MineEco is a comprehensive Minecraft plugin designed for servers running on Paper 1.8.8, providing a robust economy system and mining mechanics. It includes features such as player balances, transactions, mining rewards, levels, and a shop system. The plugin supports SQLite and MySQL databases, offers an API for developers, and includes an administrative GUI for server management. MineEco is ideal for servers looking to enhance player engagement with economy and mining mechanics.

## Install

1. Download the latest version of MineEco from the [releases page](https://github.com/EnderDevelopment/MineEco/releases).
2. Place the downloaded JAR file into your server's `plugins` folder.
3. Restart your server or use the command `/reload` to load the plugin.

## Use

1. **Basic Commands**:
   - `/saldo` - Check your balance.
   - `/pagar <player> <amount>` - Send money to another player.
   - `/baltop` - View the top balances on the server.

2. **Mining**:
   - Break blocks to earn money and experience.
   - Level up your mining skills to unlock new rewards.

3. **Shop**:
   - Use `/shop` to open the shop interface.
   - Buy and sell items using the in-game currency.

4. **Administration**:
   - Use `/economiaadmin` or `/eco` to access the administrative menu.
   - Manage player balances, economy settings, and mining rewards.
